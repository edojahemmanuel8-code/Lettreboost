## 🎯 Design Guidelines for All Mockups

### Color Palette
- **Primary Navy**: #0E1B3D (dark blue, main backgrounds)
- **Accent Blue**: #2F5FFF (highlights, CTAs, accents)
- **White**: #FFFFFF (backgrounds, text contrast)
- **Light Gray**: #F5F7FA (secondary backgrounds)
- **Dark Gray**: #2D3748 (text, body copy)

### Typography
- Headings: Bold, clean, modern sans-serif (simulate "font-display")
- Body Text: Clear, readable sans-serif
- Font sizes: Large headlines, medium subheadings, readable body text

### Layout Elements
- Header section with company/creator branding
- Hero/main visual area (use placeholder for images)
- 2-4 content sections with cards or blocks
- Call-to-action button (navy background, white text)
- Professional footer

### Style Requirements
- **Aesthetic**: Clean, modern, minimal, professional
- **Mood**: Trustworthy, engaging, premium
- **Complexity**: Medium detail - not too busy, not too bare
- **Quality**: High-resolution, polished, ready for print/email
- **Format**: 4:3 aspect ratio (800x600px minimum recommended)

## 💡 Tips for Creating Portfolio Mockups

### Using AI Design Tools (DALL-E, Midjourney, etc.):
1. Use the category-specific prompts above
2. Add specifics like: "screenshot style", "mockup", "flat design"
3. Specify the exact aspect ratio
4. Ask for "newsletter design" or "email template mockup"
5. Request modern, professional aesthetic consistently

### Using Design Software (Figma, Canva, Adobe):
1. Start with 800x600px canvas (4:3 ratio)
2. Use the color palette provided
3. Follow the layout guidelines
4. Add realistic placeholder content
5. Export as WebP for smaller file sizes

### Quality Checklist:
- ✅ Aspect ratio is 4:3
- ✅ Resolution is at least 800x600px
- ✅ File size is under 200KB
- ✅ Text is readable and professional
- ✅ Color scheme matches brand colors
- ✅ Design is engaging but not cluttered
- ✅ Includes clear CTA button
- ✅ Looks professional and finished

## 🔄 Batch Generation Tips

If creating multiple designs at once:

1. **Consistency**: Use similar styling across all designs
2. **Variety**: Make each category visually distinct
3. **Branding**: Include consistent header/branding elements
4. **Quality**: Ensure all are high-quality and polished
5. **Organization**: Save with consistent naming conventions
